# Open-Library-Api-Based-Book-Search-Engine
An Open Library API-based book search engine that returns a list of books with its information, and if provided, a book cover image according to the user's search term. 

How to run:
After loading the html page, click on the search bar and type in a book's name or author's name. Then, exit the search bar and click on the search button. The results will load and are now able to scroll through top to bottom. 

Data source credits:
Public Open Library Book Search API and olid (Open Library ID).
